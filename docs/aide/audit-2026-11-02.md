## Contrôles automatiques ajoutés

`src/help/content-rules.ts` (appliqué par `src/help/corpus.ts` au build et en test, `tests/help-content-rules.test.ts`) refuse dans tout article publié : « 500 Mo », push Web / navigateur / PWA / « écran d’accueil », 2FA / MFA / TOTP / SMS / double authentification, « V2 », « selon le déploiement », « dans la cible », « recette », « ticket » (sauf « ticket de caisse »). Un faux positif se gère par une exception datée et motivée dans le même fichier ; une exception devenue inutile fait échouer le build.
