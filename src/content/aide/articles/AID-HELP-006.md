Verebona contrôle vos droits de modification. Un compte peut devenir consultable mais non modifiable après la fin de l’essai, une résiliation ou certaines restrictions. Un quota atteint bloque la création ; un quota dépassé après changement d’offre peut bloquer les modifications.

## Procédure

1. **Lisez le message affiché** — Il doit indiquer s’il s’agit d’un quota, d’une fin d’essai ou d’un abonnement requis.
2. **Ouvrez Mon abonnement** — Vérifiez l’offre, le statut et les quotas.
3. **Si le quota est atteint** — Supprimez seulement les éléments que vous souhaitez réellement retirer ou choisissez une offre adaptée.
4. **Si l’essai est terminé** — Choisissez une offre pour reprendre l’ajout et la modification.
5. **Si le compte est en restriction de paiement** — Utilisez le parcours de régularisation.
6. **Si le message ne correspond pas à votre situation** — Contactez le support avec une capture sans données sensibles.
