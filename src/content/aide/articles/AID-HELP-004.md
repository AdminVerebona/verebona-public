L’import peut être refusé pour un format non autorisé, une taille excessive, un fichier vide, une extension incohérente, un nom dangereux, un quota atteint, un droit d’écriture bloqué ou une erreur de stockage.

## Procédure

1. **Vérifiez la taille** — 25 Mo maximum pour un document non vidéo ; 500 Mo pour une vidéo dans la route actuelle.
2. **Vérifiez le format** — Comparez avec la liste des formats autorisés.
3. **Vérifiez que le fichier s’ouvre localement** — Un fichier corrompu ou vide est refusé.
4. **Vérifiez votre quota** — L’offre peut empêcher l’ajout si la limite documentaire est atteinte.
5. **Vérifiez le bien** — Si vous rattachez le document à un bien, celui-ci doit être accessible dans votre compte.
6. **Réessayez avec un nom simple** — Évitez les extensions ou noms atypiques.
7. **Contactez le support si l’erreur persiste** — Indiquez le format, la taille et le message affiché, sans envoyer le fichier si son contenu est sensible sauf demande explicite du support.
