Lorsque le Centre d’aide et l’assistant ne permettent pas de résoudre un problème, utilisez le formulaire de contact. Un signalement précis accélère le diagnostic et limite les demandes de précisions.

## Procédure

1. **Décrivez ce que vous vouliez faire** — Une phrase simple suffit.
2. **Décrivez ce qui s’est passé** — Copiez le message exact lorsque possible.
3. **Indiquez si le problème est reproductible** — Expliquez les étapes qui le déclenchent.
4. **Ajoutez uniquement les pièces nécessaires** — Évitez d’envoyer un document patrimonial complet si une capture anonymisée suffit.
5. **Envoyez le formulaire** — Conservez la réponse du support dans le même fil si vous poursuivez l’échange.

## Détails et cas particuliers

**À indiquer** — L’écran concerné, l’action tentée, la date/heure approximative, le message d’erreur exact, votre offre si elle est pertinente et le type d’appareil/navigateur pour un problème d’affichage ou de notification.

**Capture d’écran** — Elle peut être utile, mais masquez les documents personnels, adresses, e-mails, noms de biens sensibles et autres données non nécessaires.

**Identifiants** — Ne transmettez jamais votre mot de passe, un code de réinitialisation, une clé secrète ou un numéro complet de carte bancaire.
