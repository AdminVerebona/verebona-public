Les filtres permettent de réduire temporairement la liste visible sans supprimer les éléments masqués. Si aucun résultat n’est affiché, vérifiez d’abord les filtres actifs.

## Procédure

1. **Ouvrez « Filtres »** — Une pastille indique lorsqu’un ou plusieurs filtres sont actifs.
2. **Choisissez la période** — Utilisez les options disponibles : toutes, passées, aujourd’hui ou à venir selon l’interface.
3. **Choisissez les biens** — Sélectionnez les biens dont vous souhaitez afficher les échéances.
4. **Incluez les éléments annulés si nécessaire** — Activez cette option pour les faire réapparaître.
5. **Retirez les filtres** — Revenez à la vue complète si aucune échéance attendue n’est visible.
